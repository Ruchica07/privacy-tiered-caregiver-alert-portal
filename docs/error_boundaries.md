# AegisCare — Error Boundaries & Failure Handling Matrix (Phase 3)

This document provides a comprehensive technical matrix of error boundaries, input validations, security mitigations, and safe user-facing states across the AegisCare portal and ingestion pipeline.

---

## 1. Architectural Error Isolation Principles

1. **Edge Boundary Validation:** Malformed or untrusted telemetry is quarantined immediately at the ingestion router before it can affect the database or rules engine.
2. **Fail-Closed Privacy Gating:** Any ambiguity, expired consent, or revoked permission results in strict data withholding (Tier 0 Redacted indicator).
3. **No Internal Stack Trace Leakage:** All API errors return sanitized error envelopes containing high-level category codes, human-readable explanations, and unique `correlation_id` tracking tokens.
4. **Tamper-Evident Audit Logging:** Security-relevant rejections (e.g. invalid HMAC signatures, unauthorized token claims, consent modifications) are permanently committed to the SHA-256 hash chain.

## 2. Comprehensive Failure Handling Matrix

| Failure Mode / Threat | Input Condition | Validation Boundary | System Response | User-Facing State | Audit & Logging | Security & Privacy Impact |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **Malformed JSON** | Syntactically invalid JSON payload in WebHook or REST call. | FastAPI JSON parser / Pydantic deserializer. | HTTP 400 Bad Request; execution halted. | Standardized `VALIDATION_ERROR` error envelope. | Warning logged with correlation ID. | Prevents parser crashes and deserialization exploits. |
| **Missing Required Field** | Signal payload missing `care_recipient_id` or `signal_type`. | `IngestionPipeline.validate_schema()` | Ingestion rejected; returns validation error dict. | HTTP 422 Unprocessable Entity with missing field details. | Ingestion failure logged with schema failure reason. | Prevents orphaned records in database. |
| **Invalid Data Type** | String supplied where float expected (e.g. `"value": "high"`). | Pydantic model validator. | Schema validation failure; rejected at edge. | HTTP 422 `VALIDATION_ERROR` with path identifier. | Request validation error logged. | Prevents type confusion and arithmetic exceptions. |
| **Unknown Recipient ID** | Signal or request for non-existent resident ID (`cr_999`). | Foreign key / Store lookup validator. | Request rejected or quarantined. | HTTP 404 Not Found error envelope. | Not found warning logged with requested ID. | Prevents data cross-contamination between residents. |
| **Unknown Signal Type** | Device emits unmapped signal (`signal_type: "smart_toaster"`). | `SignalType` enum validator. | Event rejected with `unknown_signal_type` status. | HTTP 400 Ingestion Error. | Ingestion rejection logged. | Protects rules engine from undefined signal states. |
| **Future Timestamp (>60s)** | Ingestion timestamp set 2 hours ahead of server UTC. | `IngestionPipeline` clock skew validator (max 60s). | Ingestion strictly rejected with `rejected_future_timestamp`. | HTTP 422 Future Timestamp rejection. | Clock-skew rejection logged. | Prevents artificial alert suppression or chronological spoofing. |
| **Duplicate Event ID** | Identical `event_id` received within 5-minute deduplication window. | Ingestion sliding-window LRU cache. | Packet flagged as duplicate; skipped from database write. | HTTP 200 `duplicate_ignored` (idempotent success). | Duplicate event logged. | Prevents double-counting, alert inflation, and data storms. |
| **Out-of-Order Telemetry** | Older event arrives after newer event has been processed. | Timestamp parsing & sorting in storage query. | Signal stored with true timestamp; chronological sorting maintained. | Normal timeline rendering; no crash. | Standard ingest logged. | Preserves historical integrity across intermittent wireless networks. |
| **Stale Telemetry** | Telemetry timestamp older than expected window (e.g. >2h heartbeat). | `FreshnessState` evaluator in data store. | Tagged as `STALE` state; badge rendered yellow. | "Last updated X hours ago — expected every Y hours" banner. | Stale status logged in fleet view. | Alerts caregiver to intermittent sensor or gateway connectivity. |
| **Missing Telemetry (Outage)** | 0 telemetry packets received for $>3\times$ expected interval. | `FreshnessState` evaluator & `check_data_gap` rule. | Tagged as `MISSING`; fires `DATA_GAP` system alert. | "Device Offline — No data received for X hours" banner. | System alert logged in audit chain. | Crucial safety boundary: distinguishes hardware failure from wellness event. |
| **Sensor High-Frequency Noise** | Sensor spikes momentarily by 40+ units above normal. | Exponential Moving Average (EMA) smoother ($\alpha=0.2$). | Value smoothed towards historical baseline; marked `noise_smoothed`. | Clean alert presentation without false panic. | Smoothing operation noted in audit details. | Suppresses false alarms caused by noisy accelerometers. |
| **Sensor Baseline Drift** | Sustained baseline shift $>15\%$ over rolling window. | Rolling baseline tracker. | Flags `drift_detected` advisory; maintains rule execution. | Maintenance advisory banner in coordinator portal. | Drift detection event logged. | Enables proactive hardware recalibration before sensor fails. |
| **Data Storm / Packet Burst** | 100+ packets delivered in single sub-second burst. | Ingestion batch queue and $O(1)$ hash deduplication. | Rapid sequential ingestion; latency $<1.0$ms per item. | Dashboard updates seamlessly without freeze. | Ingestion metrics captured. | System remains completely responsive under packet backlog recovery. |
| **Invalid HMAC Signature** | WebHook payload sent with forged or incorrect `X-Signature-256`. | `IngestionPipeline.verify_signature()` (HMAC-SHA256). | WebHook rejected immediately with HTTP 401. | HTTP 401 "Invalid HMAC-SHA256 signature". | Security alert logged in audit trail. | Prevents unauthorized external parties from injecting fake telemetry. |
| **Tampered WebHook Payload** | Valid signature header but payload modified in-transit. | HMAC-SHA256 comparison against raw body bytes. | Constant-time comparison fails; HTTP 401 raised. | HTTP 401 Unauthorized error envelope. | Tamper rejection logged in audit trail. | Guarantees cryptographic data integrity across public networks. |
| **Invalid JWT Token** | Request sent with malformed or tampered Bearer token. | `jwt.decode` with cryptographic key check. | HTTP 401 Unauthorized; token rejected. | HTTP 401 "Invalid authentication token credentials". | Authentication failure logged. | Prevents arbitrary unauthorized access to portal API. |
| **Expired JWT Token** | Bearer token past its expiration timestamp (`exp`). | `jwt.decode` expiration verification. | HTTP 401 Unauthorized; token rejected. | HTTP 401 "Authentication token has expired". | Expired session logged. | Enforces session timeout and re-authentication. |
| **Attempted Impersonation** | Authenticated caregiver requests alerts for different caregiver ID. | `verify_caregiver_access` RBAC guard. | HTTP 403 Forbidden; request aborted. | HTTP 403 "Access denied: Cannot request alerts for other caregivers". | Security authorization violation logged. | Strict anti-impersonation boundary between distinct caregivers. |
| **Revoked Resident Consent** | Resident revokes category permission for caregiver. | `filter_alert_for_caregiver()` consent lookup. | Alert withheld; redacted to Tier 0. | "Data withheld per resident consent settings". | Consent withhold event logged. | Care recipient retains full sovereignty over their private data. |
| **Unconsented Category** | Caregiver requests drill-down on category with 0 consent. | `filter_alert_for_caregiver()` consent matrix check. | Drill-down withheld; HTTP 403 raised. | HTTP 403 "Not authorized to view this alert". | Authorization block logged. | Zero unauthorized health data is ever exposed to unpermitted roles. |
| **Audit-Chain Tampering** | Malicious actor modifies a row directly in SQLite database. | SHA-256 hash-chain verification (`/api/audit/verify`). | Verification algorithm flags `is_valid: False` and identifies row. | Red "Audit Tamper Detected" banner in portal. | Tamper incident highlighted with corrupted hash index. | Cryptographically guarantees non-repudiation of audit logs. |
| **Notification Delivery Failure** | Simulated Web Push or SMS gateway timeout. | `NotificationDispatcher` retry supervisor. | Executes up to 3 bounded retries with exponential backoff. | Notification status marked as `failed` after max attempts. | `notification_failed` logged in audit chain. | Prevents silent message drops; records complete delivery lifecycle. |
| **Internal Uncaught Exception** | Unexpected Python exception in background handler. | `CorrelationIdMiddleware` global exception handler. | Exception caught; HTTP 500 error envelope returned. | Standardized `INTERNAL_ERROR` with correlation ID. | Full sanitized traceback logged to server logs. | Zero stack trace or confidential environment leakage to client. |
